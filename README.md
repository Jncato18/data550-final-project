
# NHAMCS 2018-22 Emergency Department Analysis

## Overview

This project analyzes patient-level emergency department visit data from
the National Hospital Ambulatory Medical Care Survey (NHAMCS) from
2018 through 2022. NHAMCS is conducted  by the National Center for Health 
Statistics, Centers for Disease Control and Prevention.

The final report compares selected demographic and clinical
characteristics across triage acuity levels and examines differences in
emergency department wait times across acuity levels.

## Repository Structure

- `data/nhamcs_data_2018_22.csv` contains the source dataset.

- `code/01_prepare_data.R` reads and prepares the data for analysis.

- `code/02_create_table.R` contains the code used to create the descriptive 
  table comparing patient characteristics across triage acuity levels.
  
- `code/03_create_figure.R` contains the code used to create the boxplot of 
  emergency department wait times by triage acuity level.
  
- `code/04_render_report.R` renders the R Markdown file and generates the 
  final HTML report.
  
- `output/` contains the objects generated by scripts 01, 02, and 03.
  
- `NHAMCS_Analysis.Rmd` is the R markdown file that the final report is 
  generated from.  
  
- `Makefile` defines the steps required to reproduce the final report.

- `renv.lock` records the exact R package versions used so the environment can
   be reproduced.

## Software 

This project requires:

- R version 4.2.0 or later
- Pandoc version 2.8 or later
- GNU Make 

R package dependencies are managed with renv, which records the required package 
versions in the `renv.lock` file.

## Setting up the R Environment 

After cloning the repository and opening the project, restore the required R 
packages by running the following from the root directory of the repository:
```
make install
```
This runs `renv::restore` and installs the package versions recorded in 
`renv.lock` into a project-specific R library.

## Generating the Final Report

After the R environment has been restored, run:

```
make
```

A successful build produces the following generated files:
```
output/analysis_data.rds
output/table1.rds
output/figure1.rds
NHAMCS_Analysis.html
```
The final report is `NHAMCS_Analysis.html`.

To remove the generated files and rebuild the project, run:
```
make clean
make
```
