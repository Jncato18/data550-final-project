
# NHAMCS 2018-22 Emergency Department Analysis

## Overview

This project analyzes patient-level emergency department visit data from
the National Hospital Ambulatory Medical Care Survey (NHAMCS) from
2018 through 2022.

The final report compares selected demographic and clinical
characteristics across triage acuity levels and examines differences in
emergency department wait times across acuity levels.

## Repository Structure

- `data/nhamcs_data_2018_22.csv` contains the source dataset.

- `code/01_prepare_data.R` reads and prepares the data for analysis.

- `code/02_create_table.R` contains the code used to create the descriptive 
  table comparing patient characteristics across triage acuity levels.
  
- `code/03_create_figure.R` contains the code used to create the boxplot of 
  emergency department wait times by triage acuity level.
  
- `code/04_render_report.R` renders the R Markdown file and generates the 
  final HTML report.
  
- `output/` contains the objects generated by scripts 01, 02, and 03.
  
- `NHAMCS_Analysis.Rmd` contains the written report and displays the
  generated table and figure.  
  
- `Makefile` defines the steps required to reproduce the final report.
